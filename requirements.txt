# Runtime dependencies for the deep_research engine.

# AUDIT (2026-05-30): the project previously declared NO dependency manifest
# (pyproject.toml carries only a [tool.ruff] table; there was no [project] /
# requirements file), so a clean checkout / CI runner had nothing to install —
# one of the two reasons the 71-file test suite never ran in CI. This file

#
# Versions are pinned with a compatible-release floor: `>=` the version
# resolved + verified against the suite on 2026-05-30, `<` the next major so
# CI stays reproducible without silently absorbing a breaking major bump.
# Bump the floors deliberately when upgrading.

anthropic>=0.105.2,<1.0    # clients/anthropic_client.py (messages.stream, output_config, cache_control)
httpx>=0.28.1,<1.0         # clients/anthropic_client.py (layered timeouts on the streaming path)

# cosine pass and falls back to a slower pure-Python path without it.

# Python>=3.11 — an exact-newest pin is uninstallable on the 3.10 matrix leg.
# numpy 2.x is API-stable for the cosine path across 3.10 (≤2.2.6) and 3.12.
numpy>=2.0,<3.0
